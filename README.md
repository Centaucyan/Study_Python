### Chapter 02 자료형
* type() => 자료형 확인
* len() => 문자열 길이 확인
* input() => 프롬프트에서 사용자로부터 데이터를 입력받을 때
* int(), float(), srt() => 자료형 변환
* indexing => 특정 위치에 있는 data를 참조하는 것
* slicing => 특정 범위의 data를 참조하는 것
* // => 정수 나누기 연산자
* % => 나머지 연산자
* ** => 제곱 연산자
* "{}, {}".format(1, "문자") => f"{1}, {'문자'}" 
* "{:d}".format(52), {:+d}".format(52), "{:5d}".format(52), "{:05d}".format(52) 
* .upper() => 문자열의 알파벳을 대문자로 변환 후 반환. 원본 유지(비파괴적 함수).
* .lower() => 문자열의 알파벳을 소문자로 변환 후 반환. 원본 유지(비파괴적 함수).
* .strip() => 문자열 양옆의 공백 제거. 원본 유지(비파괴적 함수).
* .lstrip(), .rstrip() => 문자열 왼쪽/오른쪽 공백 제거. 원본 유지(비파괴적 함수).
* .find(""), .rfind("") => 문자 또는 문자열을 찾아 처음 나타나는 index 번호 반환
* in 연산자 => "문자열" in "문자열"
* .split("") => ""안의 문자 또는 공백을 기준으로 기존 문자열을 잘라서 각각 원소로 하는 리스트로 반환. 원본 유지(비파괴적 함수).
